# Handoff note

Write at most 200 words, inside one code block so it is easy to copy:

```
HANDOFF: <project>, <date>
Goal: <one line>
Decided: <locked choices, as bullets>
Current state: <what works, file names, versions>
Next steps: 1. ... 2. ... 3. ...
Watch out: <known bugs, constraints>
```

Rules:
- Keep only what the next chat needs to continue the work. Drop the discussion, the dead ends and the options that were rejected.
- Use exact names: files, functions, versions, URLs, settings.
- Leave out anything already saved in Project knowledge or memory.
- Never put passwords, private keys, seed phrases or API keys in the note. Write "<stored separately>" instead.

After the block, add one line: "Start a new chat and paste this. For a long-running project, add it to the Project's knowledge instead."
